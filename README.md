# Dot Area — Acrylic Ratio Studio

底面・上面も黄金比の台形にできる、黒背景・明朝体のアクリル立体シミュレーター。

公開ページ: https://keigoyoshida7.github.io/dot-area-acrylic-studio/

## 操作

- 黄金比・低いかたち・基準サイズ・自由設計
- 斜辺32.5°・正面32.5°の2パターン。立体の4辺と底面の角度、正面図の投影角度を表示
- 底面の設置高さをcmで指定し、床から上面・底面までの高さ、天井までの余裕を立面図と返信用文章で確認
- 黄金比の対応を7つの寸法比較で表示。選択した長さを図で色分けし、φ・φ²・1/φ・1/φ²の一致と現在の差を確認
- 全12辺と6面の内角、対角線、斜高、接合角度
- 上面のずれ、板厚・密度の変更
- 3D回転、正面・側面・平面・6面展開
- 中央に高さ300 × 幅500 × 奥行300 mmの石の概形を配置。表示ON/OFFを保存可能（板展開には表示しません）
- 既存4プリセットを保ち、FILの実測開口・展示室から組立搬入の寸法上限候補を6方向で算出
- 実寸SVG、寸法CSV、設定JSONの保存と読み込み
- 底面・上面の板を加えると面積・重量・SVGに反映

## 黄金比と形の条件

「低いかたち」は、前幅W→奥行D→垂直高さHを順にφで割る構成です。前幅1618 mm、奥行約1000 mm、高さ約618 mmで、`W/D = φ`、`D/H = φ`、`W/H = φ²`。幅・高さの比には黄金比の2乗を使っています。底面・上面それぞれの前幅/後幅、上面の前幅/奥行もφです。

「黄金比は、どこに。」で底面・上面の前後幅、各平面の前幅/奥行、奥行/高さ、前幅/高さ、上面/底面の縮尺を選ぶと、実際の長さと寸法図で対応を確認できます。黄金比の判定はプリセット名やロックの状態によらず、現在の寸法から計算します。φの直接比率と、φ²・1/φ・1/φ²の設計基準を区別し、寸法変更で外れた関係は差を表示します。上面の幅と奥行が別々の倍率の場合は両方を表示し、片方だけ一致しても黄金比縮尺に一致した扱いにはしません。

初期値は底面の前幅/後幅 = φ、前幅/奥行 = φ。上面は底面を1/φ²に相似縮小するので、上面の前幅/後幅もφです。

下側の前幅W・後幅B・奥行D、上側の前幅w・奥行dに対し、上側の後幅は `b = w - (W - B) * d / D`。対応する辺を平行にして側板4枚を平面に保ちます。上面の前幅・奥行を独立に変更すると、上面の黄金比は変わります。

## 32.5°の2パターン

「斜辺 32.5°」は、立ち上がる4辺AE・BF・CG・DHと水平な底面との角度をすべて32.5°にします。底面・上面の黄金比と相似比1/φ²を保ち、上面を底面台形の外接円の中心に向けて縮小する位置へ移動します。高さは約339.416 mm、上面の前後位置は約−124.997 mmです（底面前幅1618 mm）。

「正面 32.5°」は、正面に投影したAE・BFと水平な底辺との角度を32.5°にします。上面の中心位置を保ち、高さは `(W − w) / 2 × tan(32.5°)`、初期寸法では約318.528 mmです。立体の辺と底面との角度は、奥行方向のずれも含めて計算するため、この投影角度とは異なります。

どちらも選択時に寸法を設定するプリセットです。その後の寸法変更は自由設計として扱います。FILの相似拡大・縮小では角度が維持されます。CSVには4辺の底面に対する角度と正面投影角度を記録します。

## 寸法の前提

「床から、ふたつの面まで。」の設置高さは検討値です。初期値0 cmは底面を床に置く仮定で、会場での設置位置が確定した数値ではありません。上面の高さは設置高さ＋本体の垂直高さ。FIL天井高265 cmに合わせるボタンも用意しています。開口の場合も基準面として表示し、板厚・吊り金具の補正は含みません。

設置高さは形状プリセットの切替・FIL相似拡縮時に維持し、全体リセットで0 cmに戻します。石は床の高さ0〜300 mmに固定し、アクリルのみ上下に移動します。寸法CSVと設定JSONにも設置高さを記録します。FILの室内高さの有効寸法は `2650 − 底面の設置高さ − 片側余白 × 2` mmです。負の天井余裕を表示して調整できるようにし、搬入試算が成立しない設置高さではFIL候補の適用を無効にします。

資料の数値1.618 / 1 / 高さらしき1をmとして仮定した基準サイズです。底面・上面の台形化は今回の設計案です。上面寸法・板厚・密度は調整可能な仮定値です。

SVGは板の基準面の実寸輪郭。板厚・接合・切りしろの補正は含みません。重量は選択した板の面積×板厚×仮定密度の概算です。

## FIL 搬入上限の試算

「FIL 搬入上限を算出」を開き、現在の形状を相似に拡大・縮小する上限候補を比較できます。階段入口1.12×2.40 m、階段途中1.07×3.04 m、ドア1.13×2.05 mと、展示室6.64×4.62×2.65 mを使用します。初期余白は片側20 mmです。

ドアから対面の壁までの1.36 mは「ドア後に向きを変えず直進する」仮定の上限としてON/OFFできます。角―角1.50 mは旋回判定に使えません。通路幅、階段勾配、踊り場、姿勢を変える空間が不明なため、経路全体の搬入可否は未判定です。

黄金比の初期形状・20 mm余白では、候補外形は幅1666.575×奥行1030×高さ1030.022 mm。幅方向を縦にし、奥行方向を開口幅にした姿勢です。板厚・石は拡大せず、基準面寸法のみを一様に変更します。実際の板厚のはみ出し、梱包、台車は計算に含めません。

## ローカルで使う

ビルドや外部APIは不要です。`index.html`をブラウザーで開くか、静的HTTPサーバーでこのフォルダーを配信してください。

幾何の検証: `npm test`（Node.js、追加パッケージ不要）。
